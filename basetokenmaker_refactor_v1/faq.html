FAQ

Do I need coding knowledge?

No. The current token generator asks for a token name and symbol.

What fees apply?

The current generator charges 0.005 ETH as a platform fee plus Base network gas.

Does a token have guaranteed value?

No. Deployment does not guarantee liquidity, buyers, value or returns.

Is the locker active?

No. It is disabled in this refactor until a real on-chain locking contract is implemented.
