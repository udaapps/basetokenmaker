FAQ

Frequently asked questions

Do I need coding knowledge?

No. The current generator exposes a simple name-and-symbol flow.

Do you need my seed phrase?

No. Never share a seed phrase or private key with any website or person.

What fees apply?

The current token generator charges a 0.005 ETH platform fee, plus separate Base network gas for the platform-fee and deployment transactions.

Does creating a token guarantee value or liquidity?

No. Creating a token does not guarantee buyers, liquidity, market value or returns.
